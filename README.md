# MZ-Foods

Responsive multi-page food-ordering frontend built with semantic HTML, CSS and vanilla JavaScript.

## Included features
- MZ-Foods branding and Muhammad Zaid author/developer details
- Local hero burger asset from `assets/menu-image.webp`
- Developer profile using `assets/my-image-compressed.webp`
- HTML, CSS, JavaScript, Git and GitHub skill icons
- Inline menu search (no search popup)
- Category filtering and menu navigation
- Cart with quantity controls
- Saved user profile with image upload and address CRUD
- Checkout with saved addresses and shipping fees
- Standard, Express and Same-day shipping options
- Delivery partner and payment sections in the footer
- Contact Us page
- Client-side menu CRUD on `admin.html`
- Responsive mobile navigation
- Social links intentionally set to `#`

## Important
This is a frontend demo. Profile data, cart data, menu CRUD data and addresses are stored in browser `localStorage`. No real authentication, payment gateway or order backend is connected.
