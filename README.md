📖 About The Project

MZ-Foods is a responsive multi-page food-ordering website designed and developed as a frontend web-development project.

The project focuses on creating a realistic food-ordering experience using semantic HTML, modern CSS and vanilla JavaScript, without relying on frontend frameworks.

It includes multiple pages, interactive menus, cart functionality, profile management, checkout flow, responsive navigation and browser-based data persistence.

«💡 Project Goal: Build a polished, real-world style frontend project that demonstrates practical web-development skills, responsive UI implementation and JavaScript-based interactivity.»

💾 Data Storage

MZ-Foods currently uses the browser's LocalStorage API for frontend data persistence.

The following data can be stored locally:

- 👤 User profile information
- 🖼️ Profile image
- 📍 Saved addresses
- 🛒 Cart items
- 🍔 Menu data
- ⚙️ Client-side admin changes

⚠️ Important

This is currently a frontend-only project.

There is no connected:

- ❌ Real authentication server
- ❌ Database
- ❌ Payment gateway
- ❌ Order-processing backend
- ❌ Production API

Therefore, stored data is limited to the user's browser.

---

🔐 Authentication

The login and registration interfaces are implemented as part of the frontend experience.

They are intended to demonstrate the UI and client-side user flow rather than provide production-grade authentication.

For a production application, authentication should be handled through a secure backend/service with proper password hashing, sessions/tokens and database storage.

1. Clone the repository

2. Open the project

cd Food-Website-v1.0

3. Run the website

Because this is a frontend project, you can open:

index.html

directly in your browser.

For the best development experience, use VS Code Live Server or another local development server.
